# Crypto TradeStation v1.8.4 — Performance Lab + Strategy Promotion

This build adds the first Performance Lab layer.

Included:
- New Performance Lab tab.
- Paper vs live comparison model.
- Per-symbol and per-strategy promotion candidates.
- Approved / Watch / Blocked promotion state.
- Recommended live position size per candidate.
- Clear reason for promotion, watch, or block.
- Strategy promotion snapshot exposed from BotController.
- Version label updated to v1.8.4 CTS.

Important:
- This is a decision-authority layer and dashboard.
- It does not guarantee profit.
- It is designed to prevent weak paper/live strategies from being blindly trusted with live money.
