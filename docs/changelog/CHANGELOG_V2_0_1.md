# Crypto TradeStation v2.0.1 — Clean Structured Tabs

UI cleanup:
- Top navigation now only shows six main sections:
  - Dashboard
  - AI
  - Self Learning
  - Chart
  - Settings
  - Notifications
- AI-related tools are grouped in AI Center.
- Self-learning tools are grouped in Self Learning Center.
- Chart, trade overlay, replay and journal are grouped in Chart Center.
- Editable settings, advanced settings, remote alerts and backup are grouped in Settings Center.
- Notifications, logs, remote alerts, order status and Kraken health are grouped in Notifications + Logs.

Notes:
- Existing detailed screens are still available, but they are opened from the relevant section hub instead of cluttering the top tab row.
- Version label updated to v2.0.1 CTS.
