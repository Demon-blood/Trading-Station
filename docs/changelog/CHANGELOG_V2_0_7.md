# Crypto TradeStation v2.0.7 — Live Acknowledgement + Full Backup Export

Fixes:
- Live acknowledgement is now visible directly in Settings.
- Live acknowledgement is also visible inside Settings → Basic Settings.
- Added immediate save/persist behavior when live acknowledgement is toggled.

Backup/export:
- Added Export All Settings + Data button in Backup / Export.
- Export includes settings summary, trades, open positions, tax rows, learned symbol profiles, learned strategy profiles, learned hold profiles, learning snapshots and self-learning audit rows.
- Normal app updates keep app data automatically when package name stays the same.
- API keys, secret keys, Telegram tokens and Discord webhook URLs are intentionally not exported.
