# Crypto TradeStation v2.7.7 — Chart Active Positions

Fixes:
- Chart tab no longer only shows configured symbols such as BTC/ETH.
- Chart tab now builds its symbol list from:
  - Active lifecycle positions
  - Portfolio holdings
  - Trade journal symbols
  - Configured symbols
- Added Active Position Charts chip row.
- Active symbols are marked with • ACTIVE in the all-symbol row.
- Chart tab refreshes lifecycle/portfolio while open so new active positions appear automatically.

Location:
Chart → Active Position Charts
