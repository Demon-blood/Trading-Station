# Fully Working Scope — v1.3.0

This version exposes only the features intended to be used as working app features.

## Live working connector

- Kraken spot REST API.

## Working non-live modes

- Paper trading.
- Manual trade-plan mode.
- Binance read-only market-data/signals.

## Not exposed as live connectors

- Coinbase Advanced live orders.
- Bitvavo live orders.

Those connectors remain in source as development slots, but the app UI focuses on Kraken so that the visible app is easier to understand and does not pretend unfinished connectors are live.
